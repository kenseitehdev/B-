# B Programming Language Quick Reference
# Precursor to C (Ken Thompson, 1972)

===============================================================================
[1] CONCEPT & ARCHITECTURE
===============================================================================
* Word-Oriented: B is completely typeless. Everything is a single machine word.
* Memory: A word can hold an integer, a character pointer, or an internal address.
* Conversion: No types means no casting. Pointer arithmetic is raw word math.
* Legacy: B introduced '++', '--', '+=', and the '/* */' comment style to systems programming.

===============================================================================
[2] CORE SYNTAX COMPARED TO C
===============================================================================
Feature               B Syntax                     C Equivalent
-------------------------------------------------------------------------------
Main Function         main() { ... }               int main() { ... }
Variable Declaration  auto a, b, c;                int a, b, c;
Global Variable       extrn a, b;                  extern int a, b;
Array Allocation      auto vec[10];                int vec[11]; (allocates 11 words)
String Literal        "hello\n"                     "hello\n" (packed pack into words)
Character Literal     'a'                          'a'

===============================================================================
[3] EXAMPLES
===============================================================================

--- Hello World ---
main() {
    putchar('hell');
    putchar('o, w');
    putchar('orld');
    putchar('*n'); /* '*n' is B's newline sequence */
}

--- Factorial Function ---
fact(n) {
    auto i, f;
    f = 1;
    i = 1;
    while(i <= n) {
        f =+ i; /* Note: B used '=+' instead of modern '+=' */
        i =+ 1;
    }
    return(f);
}

===============================================================================
[4] BUILT-IN OPERATORS
===============================================================================
* Arithmetic:   +  -  *  /  %
* Assignment:   =+  =-  =*  =/  =%  (Reversed order compared to modern C)
* Increment:    ++  --
* Relational:   ==  !=  <  <=  >  >=
* Bitwise:      &  |  ^  <<  >>
* Unary:        -  !  ~  * (indirection)

===============================================================================

===============================================================================
